1/25
-After much struggle, I have realize I am dumb. I have been attempting to precompute the 
derivatives and knots to save computation time. This is a good idea, usually, but of course
these objects depend on X! Instead of X we have loop_input = Y - alpha - sum (f(X_k) for k != j)
and this updates every loop. 
-The current problem is that my list of knots has too many duplicate boundary knot values. 
The reason for this is that, when taking quantiles of clustered data, I get duplicate values.
For example, if X = [0,0,0,0,0,1], then the 10th percentile is 0, but so is the 20th, 30th, etc.
This leads to the function that takes the derivative returning 0. My bandaid solution is to add
1e-16 to the list of derivatives to avoid singular matrices. It seems to work. 
-Unfortunately, my training error is plateaued at ~29.5%. I will try some combination of:
more knots, more training loops, and a looser lambda.
